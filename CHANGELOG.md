# Изменения

## 0.2.0 — 2026-09-18

- Чтение опубликованных документов онлайн без предварительной выгрузки базы: текст, поиск, структура и исходные ячейки таблиц.
- Четыре новых MCP-инструмента, ссылки на документы из каталогов, кеш в памяти и проверка SHA-256 при продолжении чтения.
- Сохранение объединённых ячеек, явные предупреждения об изображениях без OCR и о сокращённых предпросмотрах длинных ячеек.
- README с двумя сценариями работы, отдельные руководства по клиентам, онлайн-чтению, CLI, HTTP и использованию данных.

## 0.1.0 — 2026-09-18

- Первый публичный выпуск: 28 адаптеров источников, онлайн-поиск норм, фоновые загрузки с продолжением, SQLite/JSONL/Parquet.
- Локальный stdio и необязательный Streamable HTTP; сетевые режимы direct/system/proxy/ssh.
- Учёт ошибок, редакций, оригиналов, хешей и ограничений покрытия.
