# Датасет v1

Каждое задание создаёт отдельный dataset_id. В каталоге `datasets/<dataset_id>`:

- `dataset.sqlite`: таблицы `norms`, `prices`, `documents`, `receipts`.
- `norms.jsonl`, `prices.jsonl`, `documents.jsonl`: одна запись на строку.
- После экспорта Parquet: столбцы `code`, `payload_json`. Вложенный исходный JSON остаётся в `payload_json`; это формат без потерь, а не широкая плоская таблица цен.
- `raw/<sha256>.<json|xlsx|bin>`: исходные ответы. PDF/Office-оригиналы сохраняются как `.bin`, тип определяется сигнатурой.
- `manifest.json`: задания, ошибки, статус, счётчики, покрытие по источникам, хеши артефактов и источник каждого ответа.

Нормы хранят состав работ, единицы и ресурсы с исходными и числовыми значениями. «П» не превращается в ноль. Все полученные публикации сохраняются; сервер не назначает последнюю по числовому ID и не решает, какая норма применима.

Цены содержат зону, период, лист и строку XLSX, исходные значения и provenance. При ведомственном запросе `authority_id` находится в `provenance.request`. Формулы применения индекса или выбора итоговой цены не вычисляются. Исходная книга сохраняет дополнительные поля, листы и формулы, которые не вошли в нормализованные записи.

`documents` содержит целые ответы каталогов, тексты документов и ссылки на сохранённые файлы. ФССЦ/ФСЭМ/ФСБЦ, индексы и перевозки на первом этапе доступны в исходном формате; единой нормализованной таблицы для всех этих схем нет. Поиск документов возвращает небольшие карточки; текст читается порциями через `fgis_read_dataset_document`.

`complete` — все обнаруженные задания выбранного обхода выполнены. `partial` — есть ошибки; `bounded` — достигнут лимит; `cancelled` — отмена между заданиями; `interrupted` — процесс исчез; `failed` — ошибка завершения/экспорта. `fgis_resume_job` / CLI `resume` повторяет ошибки и продолжает очередь. Успешные ответы повторно проверяются по SHA-256. Изменённый raw-файл не принимается: создайте новый датасет.

`coverage_by_source` сравнивает обнаруженные и выполненные задания. Это ещё не сверка с независимым эталонным перечнем всех документов. `full_fsnb_coverage_verified` остаётся `false`: внешние ТЕР, архивы с CAPTCHA и машинные правила коэффициентов не становятся полными от успешной загрузки других источников. Получение всей страны за все периоды может превысить лимит очереди; используйте отдельные задания по источникам. Снимок большого обхода не атомарен относительно обновлений ФГИС.
