# Работа с ФГИС без датасета

Для поиска норм и чтения документов не требуется заранее скачивать базу. MCP обращается к публичной части ФГИС по мере запросов. При первом чтении документа сервер получает его полный опубликованный HTML; ИИ видит ограниченный фрагмент текста или таблицы. Исходные HTML-скрипты не исполняются, внешние изображения не загружаются.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `fgis_diagnose` | Проверить доступ через настроенный маршрут |
| `fgis_sources` | Узнать источники и ограничения адаптеров |
| `fgis_browse_source` | Перейти по каталогу, получить `document_refs` |
| `fgis_catalog` | Найти регионы, ценовые зоны и периоды |
| `fgis_search_norms` | Найти карточки норм по коду или тексту |
| `fgis_read_norm` | Прочитать норму по точному коду с составом работ и ресурсами |
| `fgis_read_document` | Прочитать текст документа порциями |
| `fgis_search_document` | Найти буквальный текст внутри одного документа |
| `fgis_document_outline` | Получить абзацы, HTML-заголовки и таблицы с позициями |
| `fgis_read_document_table` | Прочитать исходные строки и ячейки таблицы |

## Документы и технические части

1. Вызовите `fgis_browse_source` с нужным источником и переходите по возвращаемым веткам каталога. Например, `source: "fsnb2022"`, `"fer"` или `"methodologies"`.
2. Возьмите `source` и `document_guid` из `document_refs`. GUID узла каталога не обязательно является GUID документа. Дополнительная ссылка с `relation: "approving_act"` ведёт к утверждающему акту.
3. Передайте ссылку в `fgis_read_document`. Для полных ФССЦ/ФСЭМ используйте `source: "fssc"` / `"fsem"` без GUID.
4. Сохраните `provenance.sha256` и передавайте его как `expected_sha256` в дальнейшие запросы того же документа.
5. Ищите текст через `fgis_search_document`, затем читайте контекст через `fgis_read_document`. Индекс таблицы берите из `fgis_document_outline`.

Поиск не учитывает регистр и допускает разные пробелы/переносы строк. Это буквальный поиск, без семантического ранжирования. `text_status: "unavailable"` означает отсутствие доступного текста, а не отсутствие коэффициентов или нужного условия в оригинале.

## Пагинация и таблицы

- `read_document`: `offset` / `next_offset` — позиции символов Unicode; `limit` до 50 000.
- `search_document`: `offset` / `next_offset` — позиции в тексте для продолжения поиска; до 30 совпадений на запрос.
- `document_outline`: `offset` / `next_block_offset` — номера блоков, до 100 на запрос. Это структура HTML, а не восстановленное официальное оглавление.
- `read_document_table`: `table_index` — индекс из структуры; `row_offset` / `next_row_offset` — строки, до 100; `cell_offset` / `next_cell_offset` внутри каждой строки — исходные ячейки, до 50.

`rowspan` и `colspan` сохранены; объединённые ячейки не разворачиваются в новую сетку. Пустое значение, ноль и «П» различаются. Ячейка содержит до 2 000 символов предпросмотра, общий текстовый бюджет страницы таблицы — 24 000. При `text_truncated: true` прочитайте полный диапазон `offset` → `end_offset` через `fgis_read_document` порциями. Номера строк, ячеек и таблиц начинаются с нуля.

Формулы в `<sup>` / `<sub>` представлены как `^{…}` / `_{…}`. Встроенные изображения не распознаются: ответ содержит предупреждение, а оригинал нужно смотреть отдельно. Смысл формулы, применимость коэффициента и выбор редакции сервер не выводит автоматически.

## Снимок и источники

Ответы содержат название документа, URL, время получения, SHA-256 исходного ответа и отдельный хеш извлечённого текста. Для нормативного документа также возвращается URL опубликованного файла. Сохраняйте эти сведения в цитатах и выводах вместе с обладателем информации, указанным в источнике; [условия использования](DATA_USE.md).

Кеш существует только в памяти процесса: до 8 документов на 15 минут, с бюджетом 32 MiB по размеру сериализованных разобранных данных. Это не строгий предел оперативной памяти: Python-объекты и исходный HTTP-ответ требуют дополнительного места. Слишком большой документ читается, но не удерживается в кеше (`cache_retained: false`). Датасет и папка данных не создаются.

`refresh: true` принудительно обновляет документ. Если SHA-256 отличается от `expected_sha256`, сервер возвращает `SNAPSHOT_CHANGED`; заново откройте документ и получите новые позиции. Кеши разных MCP-процессов независимы. Размер ответа ФГИС и таймаут регулируются [сетевыми параметрами](NETWORK.md).
