# Сеть

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `FGIS_NETWORK` | `direct` | `direct`, `system`, `proxy`, `ssh` |
| `FGIS_PROXY_URL` | пусто | Собственный HTTP(S)-прокси для режима `proxy` |
| `FGIS_SSH_HOST` | пусто | Alias из SSH config или `user@host` для `ssh` |
| `FGIS_DATA_DIR` | системная папка данных приложения | Абсолютный путь к датасетам и заданиям |
| `FGIS_TIMEOUT` | `20` | Таймаут API, секунды |
| `FGIS_FILE_TIMEOUT` | `180` | Таймаут файлов, секунды |
| `FGIS_REQUEST_INTERVAL` | `1` | Минимальный интервал запросов одного процесса |
| `FGIS_MAX_RESPONSE_MIB` | `256` | Максимальный ответ, 1–1024 MiB; превышение фиксируется ошибкой |
| `FGIS_HTTP_TOKEN` | пусто | Bearer-токен HTTP MCP; обязателен для внешнего bind |

`direct` отключает прокси urllib. `system` использует системные настройки и proxy environment. `proxy` использует указанный пользователем адрес. `ssh` выполняет на собственном хосте `curl` через SSH в BatchMode, без интерактивного пароля; установите SSH-ключи и проверьте host key заранее. Удалённый curl должен поддерживать используемые параметры. Адрес хоста, ключи и прокси проекта не поставляются.

```json
{"env": {"FGIS_NETWORK": "ssh", "FGIS_SSH_HOST": "my-fgis-egress"}}
```

Для полного VPN-туннеля нужен маршрут вне туннеля на уровне ОС/VPN либо собственный доступный выход. Сервер не меняет системные маршруты и не выключает VPN. Наличие такого маршрута у одного разработчика не гарантирует его наличие у пользователей.

TLS проверяется через системное хранилище доверия (`truststore`). Отключения проверки сертификатов нет. HTTP 401/403 не повторяются автоматически; временные 429/5xx и сетевые сбои повторяются ограниченно. HTML вместо JSON, неожиданные схемы и превышение размера сохраняются как ошибки задания. Оригинал сохраняется до нормализации там, где ответ уже принят и распознан как JSON/файл.

После исчерпания повторов MCP-инструмент возвращает структурированный результат, а не необработанное
исключение протокола: `status`, `error_code`, `error`/`message`, `http_status`, `retryable`. Сетевой
`NETWORK_ERROR` не должен интерпретироваться как `not_found`. Сам сервер не обходит недоступность
ФГИС и не переключает маршрут автоматически.

Несколько одновременно запущенных заданий имеют отдельные ограничители запросов. Для массовой загрузки запускайте один обход. Большие полные документы могут требовать больше памяти, чем размер HTTP-ответа. Параметры размера и таймаутов можно повысить и продолжить незавершённое задание; скрытого обрезания нет.
