# Покрытие источников

Статус описывает реализованные адаптеры, а не утверждение, что все данные страны уже скачаны и сверены.

| Источник | Идентификаторы | Что сохраняется | Ограничение |
|---|---|---|---|
| ФСНБ-2022, ФСНБ-2020 | `fsnb2022`, `fsnb2020` | Деревья ГЭСН/ГЭСНм/ГЭСНп/ГЭСНр/капремонта оборудования, таблицы норм, ресурсы, сборники, дополнения, полные тексты и оригиналы | Ветки по каталогу, редакция из источника; общая полнота требует законченного обхода и сверки |
| ФЕР | `fer` | Каталог сборников, тексты с таблицами и техническими частями, оригиналы | Таблицы внутри документов не преобразованы в отдельную схему расценок |
| ФСБЦ | `fsbc_materials`, `fsbc_machines` | Полные ответы дерева базисных цен, включая листья | Исходная JSON-схема в documents/raw |
| ФССЦ, ФСЭМ | `fssc`, `fsem` | Деревья ресурсов и полный документ `/DocData/` | Крупные ответы, ограничение размера явно отражается ошибкой |
| ФССЦпг | `fssc_freight` | Дерево перевозок, исходные таблицы, документ | Формулы и коэффициенты внутри исходных таблиц |
| Методики и коэффициенты | `methodologies`, `other_methodologies`, `other_norms`, `enlarged`, `indices` | Полные документы и файлы | Нет отдельного полного реестра коэффициентов с условиями применения |
| НПА и письма | `npa`, `letters`, `other_npa` | Каталоги, тексты, файлы | Доступность зависит от публикации ФГИС |
| ПИР | `pir_methods`, `pir_surveys`, `pir_design`, `pir_indices`, `pir_examples`, `pir_archive_methods`, `pir_archive_norms` | Собственные каталоги ПИР, периоды, документы и утверждающие акты | Пустой опубликованный архив сохраняется пустым; он не подтверждает отсутствие архивов вне API |
| Федеральный реестр, включая ТЕР | `registry` | Все страницы разделов 1, 2, 6, 7, 4, 8, 5, исходные ссылки и метаданные | **Разделы 6/7 — записи о ТЕР, не полные таблицы ТЕР. Внешние сайты автоматически не обходятся** |
| Архивы ФСНБ | `archive_files` | Список доступных архивов и дополнений | **Сами ZIP за интерактивной CAPTCHA не скачиваются** |
| Зарплаты | `salaries` | Все годы, доступные в каталоге зарплат | Исторический раздел отличается от текущих цен труда |
| Сплит-формы | `split_forms` | Все регионы → зоны → выбранные периоды → XLSX, нормализованные строки | По умолчанию последний период каждой зоны, история с `all_periods` |
| Текущие индексы, труд, перевозки | `current_prices` | Зоны/периоды/ведомства, дерево групп ресурсов, индексы строительства и прямых затрат, зарплаты, доступные выгрузки 7 типов перевозки/погрузки, ведомственные сплиты | Исходные JSON/Office; отсутствующий файл или ошибка остаются в отчёте |

`include_archive` добавляет состояние «архив» к каталогам нормативных документов. Это не означает автоматического получения всех файлов архивной базы. `all_public` выбирает все строки этой таблицы. Личные кабинеты, отчётность поставщиков, мониторинг предложений, учётные данные и скрытые разделы не входят в охват.

Для доказательства полноты нужны: законченная очередь без ошибок; сверка всех страниц с `totalCount`/`total`; сохранённые листья и файлы; хеши; сравнение перечней с официальной редакцией; отдельное закрытие внешних ТЕР и архивов. Первые механизмы реализованы, полная независимая сверка всех разделов пока не выполнена.
