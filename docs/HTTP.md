# Собственный HTTP MCP

Этот режим нужен, если клиент подключается по URL или MCP работает на отдельном компьютере. Для обычного локального подключения используйте [stdio](CLIENTS.md).

## На своём компьютере

```sh
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp --transport streamable-http
```

Адрес: `http://127.0.0.1:8765/mcp`. По умолчанию сервер слушает только loopback; токен необязателен. Транспорт — **Streamable HTTP**. Отдельный старый SSE-транспорт не реализован.

## На отдельном сервере

Задайте `FGIS_HTTP_TOKEN` со случайным секретом длиной не менее 32 символов через окружение процесса или хранилище секретов. Затем запустите:

```sh
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp --transport streamable-http --host 0.0.0.0
```

Для внешнего доступа настройте HTTPS на обратном прокси перед сервером. Клиент должен передавать `Authorization: Bearer <token>`. Сам процесс TLS не завершает. Без токена достаточной длины запуск на внешнем адресе отклоняется.

Все владельцы токена получают доступ к одному хранилищу и заданиям, включая запуск, отмену и экспорт. Это режим для доверенной группы; разделения пользователей нет. Не публикуйте секрет и не выдавайте его всем посетителям сайта.

Встроенного OAuth нет. Если облачный клиент требует OAuth, одного URL и Bearer-токена недостаточно: потребуется совместимый шлюз с собственной настройкой доступа. Поддержка HTTP не означает совместимость со всеми облачными клиентами.
