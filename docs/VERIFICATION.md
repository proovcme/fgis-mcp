На проверке выявлены и исправлены: пропуск дополнений с нулевым служебным GUID; отдельные API разделов ПИР; разница схем поиска и дерева норм; доверенные сертификаты uv-managed Python; чтение больших ответов с общим дедлайном. Устаревший общий API индексов проигнорировал выбранную область и вернул глобальный счётчик; адаптер использует дерево из действующего интерфейса.

Не подтверждены: законченный национальный обход всех редакций; полные внешние ТЕР; архивы за CAPTCHA; выделение всех коэффициентов и условий применения в машинную схему; ручное подключение в каждом GUI-клиенте. Windows/Linux проверяются CI отдельно от описанного живого прогона.

Повторить корневую проверку: `uv run python scripts/verify_live.py --output .local/audit.json`. Она не запускает массовую загрузку. Для независимой проверки полноты конкретного датасета используйте его manifest, оригиналы и перечень официальной редакции; один успешный поиск или корневой ответ не заменяет эту сверку.
