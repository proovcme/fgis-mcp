# fgis-mcp

Независимый MCP-сервер для публичных данных [ФГИС ЦС](https://fgiscs.minstroyrf.ru/): ФСНБ, ФЕР, реестр ТЕР, технические части, методики, ресурсные цены, индексы, перевозки и сплит-формы. Получает первоисточники и собирает локальные датасеты для ИИ-клиентов и аналитики.

**Статус: экспериментальная версия 0.1.0.** Есть обход каталогов и контроль незавершённых заданий; полная национальная выгрузка всех редакций ещё не подтверждена. Реестр ТЕР не равен полным таблицам ТЕР. Коэффициенты сохраняются внутри документов, без автоматического выделения правил применения. [Матрица покрытия](docs/COVERAGE.md).

## Быстрый запуск через uvx

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/) и Git. Python 3.11+; uv может установить его автоматически.

```sh
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp diagnose
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp
```

Вторая команда запускает MCP через **stdio** и ожидает подключение клиента. В stdout идут только сообщения протокола. Пакет пока не опубликован на PyPI: используйте `--from`, а не просто `uvx fgis-mcp`. Для воспроизводимого запуска укажите `@<commit>` после `.git`.

## Qwen Code, Cursor, Claude Desktop, LM Studio

Добавьте сервер в раздел `mcpServers` конфигурации клиента:

```json
{
  "mcpServers": {
    "fgis": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/proovcme/fgis-mcp.git", "fgis-mcp"],
      "env": {"FGIS_NETWORK": "direct"}
    }
  }
}
```

Если приложение не видит `uvx`, укажите полный путь к исполняемому файлу. Для общего датасета нескольких клиентов задайте одинаковый абсолютный `FGIS_DATA_DIR`.

[Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/developers/tools/mcp-server/) использует `~/.qwen/settings.json`; [Cursor](https://cursor.com/docs/context/mcp) — `.cursor/mcp.json` или `~/.cursor/mcp.json`; [LM Studio](https://lmstudio.ai/docs/app/mcp) — редактор `mcp.json` в приложении. В Claude Desktop откройте Developer → Edit Config. Объединяйте разделы с существующей конфигурацией, не заменяйте весь файл.

[VS Code / Copilot](https://code.visualstudio.com/docs/agent-customization/mcp-servers) использует `.vscode/mcp.json` с корнем `servers` и `type: "stdio"`; готовый [пример](examples/vscode.mcp.json). Любой клиент, запускающий MCP-сервер как процесс, может использовать ту же команду. Проверены соединение и вызовы SDK в обычном и legacy-режиме; ручной прогон каждого перечисленного приложения не выполнен.

## Удалённое подключение

```sh
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp --transport streamable-http
```

URL: `http://127.0.0.1:8765/mcp`. Для общего сервера используйте `--host 0.0.0.0`, переменную `FGIS_HTTP_TOKEN` длиной минимум 32 символа и HTTPS перед сервером. Клиент передаёт `Authorization: Bearer <token>`. Все владельцы токена получают доступ к одному хранилищу и заданиям: это сервис для доверенной группы, без разделения пользователей. Облачным клиентам, требующим OAuth, нужен совместимый шлюз; встроенного OAuth здесь нет. Старый отдельный SSE-транспорт не реализован.

## Что попросить у ИИ

> Проверь доступ к ФГИС. Покажи доступные источники, затем скачай ФСНБ-2022, ФЕР и методики в датасет. Отдельно покажи ошибки, оставшиеся ветки и ограничения покрытия. Найди норму по коду, сохрани её редакцию и ссылку на источник. Не выбирай коэффициенты автоматически.

Порядок работы: `fgis_diagnose` → `fgis_sources` / `fgis_browse_source` → `fgis_start_download` → `fgis_job_status` → `fgis_query_dataset` / `fgis_read_dataset_document` → `fgis_export_dataset`.

- Источники: ФСНБ-2022/2020 и дополнения; ФЕР; ФСБЦ/ФССЦ/ФСЭМ/ФССЦпг; методики, НПА, письма, ПИР; реестр; архивные каталоги; зарплаты и текущие цены.
- Форматы: **SQLite**, **JSONL**, **Parquet**, исходные JSON/XLSX/PDF/Office-файлы и `manifest.json` с URL, временем и SHA-256.
- Фоновые задания переживают отключение MCP-клиента. Есть отмена между запросами и продолжение с проверкой уже сохранённых источников.
- Изменение схемы, отказ сервера, неподдержанный файл или достигнутый лимит не превращаются в успешную пустую выгрузку.

## Загрузка без ИИ

В примерах ниже `fgis-mcp` можно заменить полной командой `uvx --from … fgis-mcp` или установить CLI через `uv tool install git+https://github.com/proovcme/fgis-mcp.git`.

```sh
fgis-mcp download --source fsnb2022 --source fer --source methodologies
fgis-mcp download --zone 206 --period 427
fgis-mcp job --id <job_id>
fgis-mcp cancel --id <job_id>
fgis-mcp resume --id <job_id> --max-tasks 50000
fgis-mcp export --id <dataset_id> --format jsonl --format parquet
```

ID зоны и периода сначала получите через `fgis_catalog`: регион → ценовая зона → период. Пример 206/427 относится к Санкт-Петербургу, III квартал 2026 года; он не задаёт «текущий период» навсегда.

Для всех реализованных адаптеров, включая архивные деревья и исторические периоды:

```sh
fgis-mcp download --source all_public --include-archive --all-periods --max-tasks 200000
```

Это большой обход, потенциально на много часов и значительный объём диска. Лимит по умолчанию — 25 000 заданий, верхний — 200 000. Статус `bounded` означает остановку с оставшимися задачами; он не означает полноту. `all_public` означает все перечисленные адаптеры, а не доказанно всё содержимое ФГИС. По умолчанию в ценовых каталогах выбирается последний опубликованный период для каждой зоны; `--all-periods` включает историю.

## VPN и сеть

`direct` игнорирует системные и прикладные HTTP-прокси, но следует маршрутам ОС. **Полный VPN-туннель он не обходит.** Доступный маршрут задаёт владелец установки: исключение приложения из VPN, собственный HTTP(S)-прокси или SSH-хост. Диагностика не выдаёт любой HTTP 403 за доказанную блокировку VPN. [Настройки сети](docs/NETWORK.md).

## Разработка и проверка

```sh
uv sync --locked --group dev
uv run pytest -q
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
uv build
# Только по явному запуску обращается к ФГИС:
uv run python scripts/verify_live.py --output .local/audit.json
```

Автотесты не обращаются к ФГИС. Проверяются нормализация, отсутствие потерь нулей и неопределённых значений, сохранение редакций, продолжение, ограниченный обход, пути, хеши, stdio и HTTP с токеном. [Результаты живой проверки](docs/VERIFICATION.md), [формат датасета](docs/DATASET.md).

Код распространяется по MIT. Исходные материалы принадлежат их правообладателям; лицензия кода не переопределяет условия использования данных ФГИС. Сервер не связан с оператором ФГИС ЦС. Готовые национальные базы и пользовательские данные в репозиторий не включены.
