# fgis-mcp

### ФГИС ЦС — в вашем ИИ-клиенте

[![CI](https://github.com/proovcme/fgis-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/proovcme/fgis-mcp/actions/workflows/ci.yml)

Единый независимый MCP-сервер для работы со всеми публичными данными [ФГИС ЦС](https://fgiscs.minstroyrf.ru/) (Минстрой России). Позволяет ИИ-агентам исследовать структуру сметных нормативов, читать первоисточники, извлекать коэффициенты с условиями применения, сравнивать редакции, анализировать цены по периодам и собирать верифицированные локальные датасеты.

## Что умеет fgis-mcp

- **Находить и читать сметные нормы**: состав работ, единицы измерения, ресурсы с точным расходом (включая литеры «П» и нулевые значения).
- **Сравнивать редакции норм**: сопоставление двух редакций одной нормы с выявлением добавленных/удаленных операций и изменений в расходе ресурсов.
- **Читать технические части и методики**: пошаговое чтение текста и исходных HTML-таблиц с сохранением `rowspan`, `colspan` и разметки ячеек.
- **Извлекать коэффициенты и условия применения**: структурированное извлечение доказательств (коэффициент, условие, обоснование, контекст) с отметкой `unresolved` при неоднозначности.
- **Анализировать динамику цен**: отслеживание сметных, отпускных и базисных цен конкретного ресурса по всем опубликованным кварталам.
- **Работать с открытыми данными (OpenData)**: получение официальных паспортов наборов данных Минстроя России и прямых ссылок на дистрибутивы.
- **Формировать воспроизводимые датасеты**: сохранение ответов в SQLite, JSONL и Parquet со слоем оригиналов `raw/` и криптографическими хешами SHA-256.
- **Проверять полноту выгрузки**: математическое доказательство полноты через сверку официальных счетчиков `totalCount` и расчет многомерной матрицы покрытия.
- **Импортировать внешние файлы**: поддержка ручного импорта территориальных сметных нормативов (ТЕР) и архивов с фиксацией provenance.

## Чего fgis-mcp не делает

- **Не принимает инженерных решений**: сервер предоставляет факты и доказательства, но не выбирает применимую норму или коэффициент вместо сметчика или ИИ.
- **Не обходит защиту**: архивы за интерактивной CAPTCHA и авторизованные разделы не вскрываются автоматически. Метаданные сохраняются, а скачанный файл можно импортировать вручную.
- **Не скрапит сторонние сайты ТЕР**: записи федерального реестра и ссылки фиксируются, но автоматический обход сторонних региональных ресурсов отключен ради безопасности.
- **Не выдумывает текст**: формулы-изображения и сложные схемы требуют обращения к оригинальному файлу; OCR-галлюцинации исключены.

## Что спросить у ИИ

**Нормы и сравнение редакций**
> «Найди норму 12-01-034-02 в ФСНБ-2022. Покажи состав работ и ресурсы. Если в базе есть изменения или несколько редакций — сравни их и покажи, что изменилось.»

**Технические части и коэффициенты**
> «Открой техническую часть сборника 1 ФСНБ-2022. Извлеки все коэффициенты для стесненных условий работ вместе с исходным текстом условий и обоснованиями.»

**Цены и динамика по периодам**
> «Найди сметную цену ресурса 01.1-01-01 по Санкт-Петербургу за последний квартал и покажи, как менялась его цена по всем доступным периодам.»

**Датасет и доказательство полноты**
> «Запусти выгрузку Федерального реестра сметных нормативов. После завершения проверь полноту: сошлись ли счетчики totalCount по всем разделам?»

## Подключить за минуту

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/) и Git.

### Codex

```sh
codex mcp add fgis -- uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp
```

### Qwen Code, Claude Desktop, Cursor, VS Code

Добавьте в конфигурацию вашего MCP-клиента:

```json
{
  "mcpServers": {
    "fgis": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/proovcme/fgis-mcp.git",
        "fgis-mcp"
      ]
    }
  }
}
```

Конфигурации других клиентов: **[руководство по подключению](docs/CLIENTS.md)**.

Проверить доступность к ФГИС ЦС из терминала:

```sh
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp diagnose
```
