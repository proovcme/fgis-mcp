# fgis-mcp

### ФГИС ЦС — в вашем ИИ-клиенте

[![CI](https://github.com/proovcme/fgis-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/proovcme/fgis-mcp/actions/workflows/ci.yml)

Независимый MCP-сервер для публичной части [ФГИС ЦС](https://fgiscs.minstroyrf.ru/). Позволяет ИИ находить нормы, читать сборники и технические части, искать условия применения коэффициентов и собирать локальные датасеты с первоисточниками.

**Codex · Qwen Code · Claude Desktop · Cursor · VS Code · LM Studio · другие MCP-клиенты**

[Подключение](docs/CLIENTS.md) · [Онлайн-инструменты](docs/ONLINE.md) · [Покрытие](docs/COVERAGE.md) · [Проверки](docs/VERIFICATION.md)

## Два способа работы

| Спросить ФГИС | Собрать датасет |
|---|---|
| Найти норму и прочитать её ресурсы | Скачать выбранные источники, зоны и периоды |
| Открыть техническую часть или методику | Сохранить оригиналы, редакции, URL и SHA-256 |
| Найти текст и прочитать строки таблицы | Работать с SQLite, JSONL и Parquet |
| Без предварительного скачивания базы | Продолжить прерванное фоновое задание |

Онлайн-режим получает нужный документ по запросу и временно хранит его в памяти. Датасет на диске для этого не требуется.

## Подключить за минуту

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/) и Git. Используется Python 3.11+; uv может установить его автоматически.

### Codex

```sh
codex mcp add fgis -- uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp
```

Перезапустите клиент после добавления. Проверьте запись через `codex mcp list`, подключение и инструменты — через `/mcp` в Codex. Для ручной настройки есть [готовый config.toml](examples/codex.config.toml) и [инструкция для Codex](docs/CLIENTS.md#codex).

### Qwen Code и клиенты с mcpServers

Добавьте сервер в конфигурацию MCP-клиента. Для **Qwen Code** это `~/.qwen/settings.json`:

```json
{
  "mcpServers": {
    "fgis": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/proovcme/fgis-mcp.git",
        "fgis-mcp"
      ]
    }
  }
}
```

Клиент сам запускает сервер через stdio. Если приложение не видит `uvx`, укажите полный путь к нему. Существующие настройки сохраните, добавив только запись `fgis`.

Пакет пока не опубликован на PyPI — параметр `--from` нужен. Конфигурации остальных клиентов и закрепление версии: **[руководство по подключению](docs/CLIENTS.md)**.

Проверить доступ к ФГИС из терминала:

```sh
uvx --from git+https://github.com/proovcme/fgis-mcp.git fgis-mcp diagnose
```

## Что спросить

**Нормы и ресурсы**

> Найди в ФГИС норму по моему коду. Покажи состав работ, единицу измерения и ресурсы. Укажи редакцию и источник; если найдено несколько публикаций, покажи различия.

**Технические части и коэффициенты**

> Открой сборник ФСНБ-2022 по земляным работам. Найди в технической части коэффициенты для стеснённых условий, прочитай соответствующие таблицы и примечания. Приведи основания, а если подходящего условия нет — сообщи об этом.

**Датасет**

> Найди ценовую зону Санкт-Петербурга и доступные периоды. Скачай сплит-форму за выбранный квартал, дождись завершения и экспортируй в Parquet. Покажи ошибки и ограничения покрытия.

Сервер возвращает данные и контекст источника. Он не выбирает применимую норму, коэффициент или редакцию вместо пользователя и ИИ.

## Что доступно

ФСНБ-2022 и ФСНБ-2020, ФЕР, базисные цены, методики, НПА, письма, ПИР, федеральный реестр, ресурсные цены, зарплаты, индексы, перевозки и сплит-формы — через 28 адаптеров источников и 19 MCP-инструментов.

**Версия 0.2.0, экспериментальная.** Полная выгрузка всех редакций по стране ещё не подтверждена. ТЕР представлены записями реестра и ссылками; внешние базы автоматически не скачиваются. Архивы за CAPTCHA не обходятся. Таблицы читаются с исходными ячейками, но единого машиночитаемого реестра всех коэффициентов и условий применения пока нет. Формулы-картинки требуют просмотра оригинала.

## Разработка

```sh
uv sync --locked --group dev
uv run pytest -q
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
uv build
```

Автотесты работают без обращений к ФГИС. Для явной проверки корневых каталогов: `uv run python scripts/verify_live.py --output .local/audit.json`. Массовую загрузку эта команда не запускает.

Нашли ошибку? [Создайте issue](https://github.com/proovcme/fgis-mcp/issues), указав версию, источник и обезличенный текст ошибки.
